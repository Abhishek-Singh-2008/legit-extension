How to connect

  1. Go to GitHub → Settings → Fine-grained tokens → Generate new token
  2. Set Resource owner to your GitHub username
  3. Under Repository access, choose Only selected repositories → select your LeetCode solutions repository
  4. Under Repository permissions, set Contents to Read and write
  5. Generate the token, copy it, and paste it below

Your token is stored locally and never sent outside of GitHub API calls.
